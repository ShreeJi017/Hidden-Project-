MODULE 08 · LOCAL-FIRST ROUTING

Offline mode

Mode · Automatic

Automatic uses supported local tools first, then the configured online provider. Offline-only never sends AI chat or provider-test requests online. Online-only sends chat to the configured provider. Mode changes apply to new requests; an online request already in progress cannot be recalled.

Network Checking…

AI availability Checking…

Local model No inference engine installed

On-device model

No compatible on-device inference engine or installed model is available. Browser speech APIs are not local AI inference. Models are never downloaded automatically.

A future native engine must discover/import a compatible model and check available RAM and storage before loading. Downloads require a separate explicit confirmation. Local wake-word detection, offline STT, and local TTS are not provided by this web app.

Memory is saved only when you choose Save local memory, or explicitly ask chat to “remember that …”. It is never automatically added to online prompts.

MODULE 09 · EXPLICIT ANDROID ACTIONS

Phone Actions

Bridge · Checking…

Commands from chat or speech are checked before AI routing. An ordinary browser cannot control Android. Sensitive Android actions require confirmation; calls also require Android’s call permission. Text commands only open a prefilled messaging draft; ZeroGravity never sends SMS. Calendar commands open a draft in a calendar app for you to save. Notification text is shown only after you grant Android notification-listener access.

    MODULE 07 · PROVIDER ROUTING

    Own API

    Development-only direct browser requests. This app has no secure backend proxy. API keys, custom header values, custom static bodies, and arbitrary request settings are held in page memory only; they are not saved in browser storage and are lost when the page reloads. Allow-listed non-secret image, search, and weather field mappings may be saved with provider metadata. A browser key can still be exposed to scripts, extensions, network tooling, or anyone with access to this active session. For production or sensitive use, route requests through a trusted backend. Never put credentials in endpoint URLs.

    Provider dashboard

    Choose separate providers for each function. Only adapters listed as available execute requests.

    DIRECT-BROWSER · SESSION ONLY

    Provider configuration

    Provider requests originate in this browser and require provider CORS support. No connection result is assumed: use Test connection. Automatic fallback is attempted only between configured Chat Completions-compatible Chat AI providers.
